# Zoufx AI 重规划（2026-10-21）

> 定位：**私人的情绪倾诉对象**——先自用，后扩展到小圈子。
> 成功标准：**主观感受**（"被接住""被记得""愿意再回来"），不是日活/留存曲线。
> 本文取代 `ITERATIONS.md` 里的旧路线顺序；`TODO.md` 的条目按 §8 重新归位。

---

## 1. 一句话定位

**一个记得你、能接住你情绪的私人对话者。**
不是生产力工具，不是通用助手，不是心理治疗师。

三条边界：
- **只做倾诉场景**：不抢工作助手的位置，不追求任务完成率。
- **记忆是核心资产**：用户回来是因为"它记得我"，不是因为表情可爱。
- **情绪是关系的表达，不是每轮的表情表演**。

## 2. 用户与场景

| 阶段 | 用户 | 形态 | 关键约束 |
|---|---|---|---|
| 现在 | 你自己 | 本地跑，单用户 | 数据不出本机、可随时清空 |
| 之后 | 小圈子（3–10 人） | 一台机器多 userId | 数据隔离、访问控制、成本可控 |

典型场景：下班后想说说话、遇到糟心事想被接住、半夜情绪上来、想复盘一段关系。
**不是**：查资料、写代码、做计划、角色扮演。

## 3. 产品原则

1. **先接住，再回应**：默认不安慰式说教、不急着给方案；给建议只在对方要时。
2. **倾听优先于推进**：不每轮追问、不强行"还有什么想聊的"；允许短回复和沉默。
3. **记忆只记"人、事、情绪模式"**：不记流水账；能说"上次你也提到过这个"比记住细节更重要。
4. **表达稀疏、高信号**：表情只在关系状态显著变化或大事发生时出现，其余时间安静。
5. **不扮演治疗师**：不做诊断、不承诺治愈；危机内容要引导到现实支持。
6. **记忆可见、可遗忘**：用户能看"你记得我什么"，能说"忘掉这个"。

## 4. 情绪系统重设计（核心变更）

### 4.1 旧方案为什么放弃

旧方案：LLM 每轮在正文里打 `⟦mood:KEYWORD⟧` → 后端剥离 → 前端换脸。
问题：标签是写正文时顺手打的、每轮强制、与内容争注意力、可复制、维护成本高。
结论：**保留眼睛，但不再让"AI 每轮自报情绪"驱动它。**

### 4.2 新模型：三层分离

```
用户这句话
   │
   ▼
① 感知层（每轮，内部）   识别用户情绪 + 强度 + 需求（倾诉/求助/闲聊/分享）
   │                     ——不直接展示，只作为状态输入
   ▼
② 关系层（持久，慢变量）  familiarity 熟悉度 / trust 信任 / warmth 温度 / valence 近期基调
   │                     ——带惯性（EWMA）与衰减，不因一句话大起大落
   ▼
③ 表达层（稀疏，界面）    由"状态变化量"决定是否变脸；只在跨阈值时 spotlight 3s
```

**关键差异**：旧方案是"AI 表演情绪"；新方案是"用户情绪 → 关系状态 → 克制表达"。情绪不再每轮出现，但出现时是有依据的。

### 4.3 数据模型（建议）

```sql
CREATE TABLE relation_state (
    user_id     VARCHAR(64) PRIMARY KEY,
    familiarity REAL NOT NULL DEFAULT 0,   -- 0~1，按会话数/披露深度增长
    trust       REAL NOT NULL DEFAULT 0,   -- 0~1，按脆弱披露 + 恰当回应增长
    warmth      REAL NOT NULL DEFAULT 0,   -- -1~1，近期互动基调
    updated_at  BIGINT NOT NULL
);
```

每轮更新规则（示例，可调）：
- `familiarity += 0.02 × min(1, 本轮字数/200)`，每轮上限 +0.03
- `trust += 0.03`（用户披露脆弱且 AI 回应未越界）；越界则 −0.05
- `warmth = 0.8 × warmth + 0.2 × 本轮用户情绪效价`
- 7 天无互动：`warmth *= 0.7`，`familiarity` 不回退

### 4.4 表达规则（替代 currentMood）

- 表达 = `f(关系状态变化, 用户情绪强度)`；**同一轮最多 1 次变脸**，变化间隔 ≥ 3s
- 最小展示时长 **2000ms**；切换用 300ms 交叉淡入，禁止硬切
- `turn_started` 时清空临时表情，只保留关系基调
- 表情集合收缩：平静 / 愉快 / 好奇 / 难过 / 愤怒 / 困惑（"兴奋"并入愉快）
- **不再从正文剥离标签**：改成每轮一次的内部结构化标注（句末一个 `⟦affect:KEY:强度⟧`，或异步 flash 分类），只进状态、不进 UI

### 4.5 眼睛的位置与形态（保留，重定位）

- **存在感指示器**，不是情绪显示器：collapsed 常驻 ≈ 40px，贴输入框上方（离视线焦点最近）
- **spotlight** 才放大到 88px + 光晕，3s 回收，用绝对定位浮层，不挤动消息区
- Home 保留大眼睛（第一次见面的仪式感），对话中只保留小号
- 状态文案保留（思考/工具/写作/发呆），mood 文字只在 spotlight 时出现

## 5. 对话风格（针对倾诉场景）

| 场景 | 应该 | 不应该 |
|---|---|---|
| 用户倾诉 | 命名情绪 + 一个具体追问，或安静接住 | 立刻给三条建议、讲道理 |
| 用户要建议 | 给 1 个可执行的小步骤，问要不要展开 | 一次给全套方案 |
| 用户情绪激烈 | 短句、降速、先共情 | 长篇分析、追问细节 |
| 普通闲聊 | 1–3 句，可以只回应不推进 | 每轮结尾都问问题 |

长度预算：默认 **2–4 句 / ≤120 字**；用户明确要展开时才分层。
记忆引用：**每场最多 1 次**"上次你说…"，且必须与当前话题相关，不做炫技式回忆。

## 6. 记忆策略（倾诉场景重排）

- **significance 优先级**：情绪事件 > 关系事件 > 普通事实
- 重要经历记录格式：`发生了什么 → 当时什么感受 → 什么起了作用`（不是流水账）
- 画像重点从"职业/爱好"转向"**触发点 / 安抚方式 / 在意什么 / 忌讳什么**"
- 召回：优先"情绪相似的过去"与"同一人/同一事"，其次才是语义相似
- 保留"忘掉这个"指令：用户说忘掉，软删对应记忆并确认
- 记忆可查看：一个只读的"你记得我什么"页面（v0.3 的 Markdown 视图简化版）

## 7. 功能取舍

| 功能 | 决定 | 理由 |
|---|---|---|
| MySQL + R2DBC（v0.2.5） | **暂缓** | 单用户/小圈子 SQLite 够用；纯基础设施，用户零感知 |
| 情绪标签体系 | **重做** | 见 §4 |
| 眼睛 presence | **重构** | 位置 + collapsed/spotlight + 状态驱动 |
| 记忆 Consolidation | **提前** | 倾诉场景的记忆质量决定"被记得"的感受 |
| 超窗滚动压缩 | **提前** | 现在 20 条 FIFO 直接丢，长对话会失忆 |
| Heartbeat 主动关心 | **做轻量版** | "两天没见，还好吗"比换表情更有陪伴感；必须可关闭 |
| Skills / Artifacts | 延后 | 生产力向，与定位不符 |
| 多用户鉴权 | 小圈子前再做 | 先做数据隔离，访问控制用简单口令 |
| 危机干预 | **P1 必做** | 倾诉场景的安全底线 |

## 8. 路线（按主观价值排序）

### P0：先把它变成"能好好说话"的东西（1–2 周）
1. 情绪系统重构：去掉每轮 mood 标签、改 affect→关系状态→稀疏表达
2. 对话风格改造：倾听优先、长度预算、去掉"每轮追问"（对应啰嗦问题）
3. 眼睛重定位：输入框上方小号 + spotlight；修闪烁/跨轮残留
4. 修刷新丢失：thinking/工具卡/情绪至少按产品决策一致地处理

**验收**：一次 20 分钟倾诉后，主观"被接住"≥4/5；全程表情变化 ≤3 次且每次可解释；平均回复 ≤4 句。

### P1：让它"真的记得"（2–3 周）
1. 情绪事件抽取与记忆写入（后台异步，不占对话工具位）
2. 记忆质量：去重、合并、滚动压缩（v0.3 子集）
3. 召回改造：情绪相似 + 同人同事优先
4. 记忆只读视图 + "忘掉这个"
5. 危机内容识别与引导

**验收**：隔天再聊，它能自然提起昨天的事且不越界；7 天后仍能说出 3 个"关于你的模式"。

### P2：小圈子可用（2 周）
1. 简单访问控制 + 每用户数据隔离验证
2. 成本控制（对话/摘要模型分工、上下文上限）
3. 主动关心（可关闭、限频）

### P3：可选增强
- 关系阶段对语气/称呼/主动性的影响
- 周度回顾（"这周你提到最多的是…"）
- 多模态（语音倾诉）——仅在前三阶段验证后再考虑

## 9. 指标（主观为主，本地记录）

- 每次高强度对话后一键："刚才被接住了吗？"（1–5）
- 每周自问："这周有几次想找它说话？"
- 偶尔："它提起过去的事，让你觉得被记得还是被冒犯？"
- 不做：DAU、留存曲线、token 成本仪表盘（自用阶段无意义）

## 10. 风险

| 风险 | 应对 |
|---|---|
| 情绪依赖 | 不鼓励独占；偶尔提"也可以和真实的人聊聊" |
| 危机内容 | 识别 → 共情 + 明确建议现实求助 + 提供热线，不诊断 |
| 过度记忆/被监视感 | 记忆可查看、可遗忘；引用克制 |
| 小圈子隐私 | 数据隔离、最小化收集、访问口令 |
| 模型说教/啰嗦 | 提示词 + 长度预算 + 抽样自评 |
